# 4. 60 Individual Challenge Days

### Prompt

> Every day must have its own challenge. Create realistic programming challenges for Day 1 through Day 60.

Each challenge should include:

* Unique challenge title
* Difficulty
* Estimated completion time
* Learning objective
* Detailed task description
* Acceptance criteria
* Helpful resources
* XP reward
* Badge reward

### AI Assistance

AI helped structure the challenge system and progressive learning path.

The suggested progression included:

* Days 1–10 → HTML, CSS, JavaScript basics
* Days 11–20 → DOM, APIs, Forms
* Days 21–30 → Intermediate JavaScript
* Days 31–40 → Algorithms and mini projects
* Days 41–50 → Advanced JavaScript and performance
* Days 51–60 → Portfolio-level projects

### Implementation

The challenge structure was integrated into the ABTalks experience with progressive difficulty and unique daily tasks.
