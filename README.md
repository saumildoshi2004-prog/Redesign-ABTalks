# 🚀 ABTalks Redesign – 60-Day Coding Challenge

> A modern, mobile-first redesign of the **ABTalks** platform created for a UI/UX & Frontend Hackathon.

---

## 📖 Overview

ABTalks is a **60-day coding challenge platform** that encourages students to build projects consistently while maintaining a public learning streak through GitHub commits and LinkedIn posts.

This project reimagines the platform with a **clean, modern, mobile-first experience** focused on motivation, simplicity, and engagement.

The redesign aims to make students excited to return every day and complete the challenge while building a strong public portfolio.
